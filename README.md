# Music Store SQL Analysis

A data analysis project using **PostgreSQL** to explore and analyze a digital music store database.

## 📌 Project Overview

This project analyzes music store data to answer business-related questions about customers, artists, albums, tracks, genres, invoices, and sales.

The analysis demonstrates practical SQL skills including data filtering, aggregation, joins, subqueries, CTEs, and analytical functions.

## 🛠️ Tools & Technologies

* PostgreSQL
* pgAdmin 4
* SQL
* GitHub

## 🔍 Analysis Areas

* Customer purchasing behavior
* Sales and revenue analysis
* Popular music genres
* Top-performing artists
* Track and album analysis
* Customer spending patterns
* Country-wise sales analysis
* Track duration analysis
